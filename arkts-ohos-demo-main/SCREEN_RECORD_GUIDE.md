# 录屏指南 - 电影点赞功能演示

## 功能演示步骤

### 1. 启动应用
- 在DevEco Studio中运行应用
- 选择HarmonyOS模拟器或连接真机
- 等待应用启动完成

### 2. 演示内容

#### 场景一：首页电影列表点赞
1. 进入应用首页（电影列表页）
2. 向下滑动浏览电影列表
3. 点击任意电影的点赞按钮（红色心形表示已点赞，灰色空心表示未点赞）
4. 观察点赞数变化
5. 点击多个电影的点赞按钮，测试切换功能

#### 场景二：电影详情页点赞
1. 点击任意电影进入详情页
2. 在电影标题下方找到点赞按钮
3. 点击点赞按钮，观察状态变化
4. 返回首页，检查相同电影的点赞状态是否同步

#### 场景三：排行榜页面点赞
1. 从首页或关于页进入排行榜页面
2. 在票房排行榜和评分排行榜中
3. 点击不同电影的点赞按钮
4. 观察点赞状态和数量的实时更新

#### 场景四：跨页面同步测试
1. 在首页点赞某部电影
2. 进入该电影的详情页，验证点赞状态
3. 进入排行榜页面，找到同一部电影，验证点赞状态
4. 取消点赞，验证所有页面同步更新

### 3. 录屏要点

#### 技术要点展示：
- 点赞按钮的UI状态变化（颜色、图标）
- 点赞数字的实时更新
- 跨页面的状态同步
- 内存中状态保持（应用内）

#### 用户体验展示：
- 流畅的点击反馈
- 直观的状态指示
- 一致的用户体验

### 4. 录制建议

#### 设备设置：
- 使用HarmonyOS模拟器（Phone API 9+）
- 分辨率：720x1280 或 1080x1920
- 帧率：30fps

#### 录制软件：
- DevEco Studio内置录屏功能
- 或使用OBS Studio
- 或使用系统自带录屏工具

#### 录制时长：
- 总时长：1-2分钟
- 每个场景：20-30秒

### 5. 预期效果

#### 视觉反馈：
- 未点赞状态：灰色空心心形 ♡
- 已点赞状态：红色实心心形 ♥
- 点赞数：显示在图标右侧
- 按钮边框颜色与状态同步

#### 交互反馈：
- 点击后立即更新UI
- 状态变化有视觉反馈
- 跨页面数据一致性

### 8. 注意事项

1. **网络连接**：确保可以访问GitHub
2. **文件大小**：录屏文件建议压缩到100MB以内
3. **清晰度**：确保文字和按钮清晰可见
4. **演示流程**：按照上述步骤有序演示
5. **功能完整性**：展示所有新增功能点

### 9. 故障排除

如果录屏遇到问题：

1. **模拟器无法启动**：检查DevEco Studio配置
2. **应用崩溃**：检查代码编译是否成功
3. **点赞状态不同步**：确保LikeService正确初始化
4. **UI不更新**：检查@State装饰器是否正确使用
